Fixes for calls that the server drops, and for calls left open by mistake.

## Installing

If you're on 1.1.0 or later, there's nothing to do. Hopp updates itself once you're not on a call and its window isn't in front.

If you're on stock Hopp, or the update doesn't arrive, paste this into Terminal. It quits Hopp, installs the new version and reopens it:

```
curl -fsSL https://raw.githubusercontent.com/useforesight/hopp/main/install.sh | bash
```

You stay signed in. Coming from stock Hopp, macOS asks for Hopp's permissions again.

## What's fixed

**Dropped calls**

Before, when the server ended your part of a call, Hopp kept showing it as live with nobody in it. Now:

- **You joined from somewhere else**, such as a room link opened in a browser: you can only be in a call once, so Hopp leaves it on this computer and offers **Rejoin here**.
- **The call was closed**, or you were removed from it: Hopp leaves it and says so.
- **The connection dropped for good**: Hopp rejoins by itself.

**Empty calls**

- A call with someone ends once you've been alone in it for 5 minutes, and Hopp tells you. Before, a call left open by mistake kept your mic and camera on and showed you as in a call, so anyone who joined you was on their own. Rooms stay open, because they're somewhere to wait for people.

**Captures**

- If a capture's Markdown copy couldn't be saved, for example because the disk was full, Hopp writes it once your next capture finishes. The transcript itself was never lost.

## Good to know

- The Linux client, built from source, can now set and show statuses. It also plays H.265 screen shares on hardware that can decode them, so a Mac sharing a 5K screen no longer has to shrink it there.
