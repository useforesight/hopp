Know who's sharing their screen, and find it straight away.

## Installing

If you're on 1.1.0 or later, there's nothing to do. Hopp updates itself once you're not on a call and its window isn't in front.

If you're on stock Hopp, or the update doesn't arrive, paste this into Terminal. It quits Hopp, installs the new version and reopens it:

```
curl -fsSL https://raw.githubusercontent.com/useforesight/hopp/main/install.sh | bash
```

You stay signed in. Coming from stock Hopp, macOS asks for Hopp's permissions again.

## What's new

- **The sharer is marked.** In the camera window, whoever is sharing has a green ring and a "Sharing" badge. Click the badge to bring their screen to you. Your own tile says so too while you share.
- **The shared screen comes to you.** When someone starts sharing, their screen opens on the display and Space you're using, rather than wherever the window was last time. If you can already see it, it stays where you put it.
- **The call panel names them.** "Open shared window" in Hopp's menu-bar panel now reads "View Sam's screen", with the sharer's name.

## Good to know

- Only you need this release to see these. Nothing changes for the person sharing.
- No server change is needed.
