The first release of this fork, based on Hopp 1.0.33.

## Installing

On a Mac, paste this into Terminal. It quits Hopp, installs the new version and reopens it:

```
curl -fsSL https://raw.githubusercontent.com/useforesight/hopp/main/install.sh | bash
```

You stay signed in, and it updates itself from now on. macOS will ask for Hopp's permissions again, so grant them when it does.

If you'd rather use the DMG below (`aarch64` for Apple Silicon, `x64` for Intel), macOS blocks it the first time, because it isn't notarized by Apple. Go to System Settings > Privacy & Security and choose Open Anyway.

You can still call people on the old version.

## What's new

**Calls you can't miss**

- An incoming call stays on screen until you answer or decline it, including over fullscreen apps.
- Missed calls are saved until you deal with them: a card with who and when, a red badge on the menu bar icon, and a Missed section in People.
- If someone rings while you're on a call, they hear you're busy, and you get a quiet card with Call back.

**Calls that recover**

- A stalled mic, speaker or camera restarts by itself. If that fails, Hopp tells you and offers a fix.
- If the call engine crashes, it restarts and rejoins the call with your mic and camera as they were.

**Drawing**

- Strokes are smooth and show up clearly on light and dark screens.
- Drawings fade out together after a pause, not one line at a time.
- Hold Shift for a straight line, press Cmd+Z to undo, and right-click to clear.
- Drawing starts straight away, with a short hint on screen showing the controls.

**A new look**

- Dark mode: Auto, Light or Dark, from the user menu or Settings.
- Every window is redesigned.
- In People, search has focus when the window opens. Arrow keys move through results and Return runs the highlighted action, which can place a call.

**Fewer surprise shortcuts**

- The camera (Cmd+Shift+V), Cmd+Shift+W and Cmd+Shift+S shortcuts are now off by default. You can turn them on in Settings. Mic (Cmd+Shift+A) stays on.

**Call from Raycast (optional)**

- Type a teammate's name in Raycast and press return to ring them. To install it, run `npm install && npm run dev` in the repo's `raycast` folder with Hopp open.

## Good to know

- If you use your own server, updating keeps it. On a new install, use the link on the sign-in screen to set it before you sign in.
- Feedback after a call now goes to the server you're signed in to. It used to go to stock Hopp's server, along with your sign-in token, even if you were using your own.
- If your laptop is asleep or Hopp is closed, you show as offline and nobody can ring you, so those calls aren't recorded as missed.
- "Report an issue" in the app now goes to this repo, which is public, so check logs before you paste them.
