Prototype only. Keys 1–6 switch scenes, Super Alt H in the real client toggles the bar panel. Colours follow the active Omarchy theme; try the theme picker.

1 · No main window

Hopp lives in the Omarchy bar as a shell plugin (same shape as local.otuple). Teammates, rooms, presence and call controls sit in a keyboard-driven panel. Nothing occupies a tile until you're actually looking at someone's screen.

2 · Faces are fixed-size

The call window is a small floating, pinned window whose size is derived from the participant count: tile × n + gaps. Cameras are centre-cropped to square (cover), never stretched. Resize snaps between three tile sizes (S/M/L) instead of free-form stretching. Column, row or bubble layouts.

3 · Viewing a share in a tiling WM

A tile has whatever shape Hyprland gives it, and a screen has a fixed one, so fitting one into the other always leaves bars. Instead, the tiled viewer is a viewport: readable scale, cropped to the tile, following the sharer's cursor, with a minimap. For the whole screen at once, Super+H opens it fitted in a special workspace, monitor to monitor.

Hyprland rules shipped with the client

-- ~/.config/hypr/apps/hopp.lua
o.window("app.gethopp.faces", {
  float = true, pin = true,
  move = { "100%-w-10", "100%-w-10" },
  no_initial_focus = true,
  keep_aspect_ratio = true,
  no_screen_share = true,
})
o.window("app.gethopp.viewer", {
  tag = "-floating-window", -- tiles normally
})
o.window("app.gethopp.peek", {
  workspace = "special:hopp",
})
-- Super+H: whole remote screen over anything
o.bind("SUPER, H", "Hopp peek",
  "hyprctl dispatch togglespecialworkspace hopp")

How it maps onto the current code

  • Bar plugin: QML Widget.qml + Service.qml talking to the GPUI client over the existing private IPC socket (instance.rs).
  • GPUI client becomes headless-by-default and opens up to two windows: faces and viewer, with distinct app IDs.
  • Toast: Omarchy notification with actions, or a layer-shell surface (we already use layer-shell for cursors).
  • Share border/pill: reuse the existing output-bound overlay layer in cursor_overlay.rs.

Keyboard first

  • Super Alt H open the Hopp panel, / search, ⏎ call
  • Super Shift M mute anywhere · Super Shift S share
  • Super Ctrl Esc revoke control (global, already a CLI flag)
  • Esc Esc release control when driving someone's screen
